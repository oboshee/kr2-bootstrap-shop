# Контрольная работа №2: Bootstrap Shop

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием фреймворка Bootstrap 5.

## Практическая работа 9
- Создан проект и подключён Bootstrap через CDN.
- Реализована главная страница с использованием сетки (`container`, `row`, `col-*`).
- Добавлены блоки преимуществ и популярных товаров.

## Практическая работа 10
- Добавлена единая навигация (`navbar`) на все страницы.
- Использованы компоненты `card`, `btn`, `badge`, `alert`.
- Создано модальное окно (`modal`).
- Создана форма заявки с использованием `form-control`, `input-group`, `form-check`, `form-select`.
- Добавлен компонент `accordion` на страницу товара.

## Структура проекта
- `index.html` – главная страница
- `catalog.html` – каталог товаров
- `product.html` – страница товара
- `order.html` – форма заявки
- `css/custom.css` – дополнительные стили
- `images/` – папка для изображений
- `README.md` – описание проекта
